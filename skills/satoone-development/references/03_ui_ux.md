# UI e UX

A interface deve transmitir Tesla, Apple HIG, Steam Deck e Linux moderno: escura, fluida e claramente não padrão do Qt. Usar fundo `#050505`, primária `#00BFFF`, destaque `#55CFFF`, fontes sans-serif modernas, cantos arredondados e efeitos de vidro somente quando o custo gráfico for aceitável.

Usar animações intencionais de fade, opacidade, glow e partículas, com meta de 60 FPS. Suportar touch e teclado físico nas rotas críticas.

A splash deve conter logo centralizada, partículas, glow, barra própria, fade in/out e mensagens profissionais, abrindo automaticamente o Dashboard. O Dashboard exibe CPU, RAM, temperatura, bateria, Wi-Fi, Bluetooth, IA, rede, serviços, lançadores, notificações e relógio; cada métrica é coletada por serviço/driver, nunca pelo widget.
