# Notas de engenharia

Usar `knowledge/` para notas datadas por domínio. Incluir contexto, evidência, estado e links para especificações afetadas.

Classificar cada afirmação como medição física, especificação de fabricante, estimativa, meta, candidato ou pendente de validação. Preservar fotos e vídeo como evidência da V0, sem inferir deles especificações elétricas.
