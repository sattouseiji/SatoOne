# Project Knowledge Base

Memória técnica permanente do SatoOne. Registre fatos, tentativas, decisões e resultados — inclusive falhas e acertos. Cada nota deve ter data, contexto, evidência, status e links para arquivos afetados.

Para um novo incidente: crie/atualize uma nota em `bugs/`, a correção em `fixes/` e uma entrada cronológica em `debug_history.md`.

Para uma implementação comprovada: registre o resultado e por que funcionou em `successes/engineering_success_history.md`.
