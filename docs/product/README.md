# Estratégia de produto

## Posicionamento

SatoOne é um computador pessoal portátil proprietário em desenvolvimento. O projeto público existe para apresentar o produto, documentar marcos verificáveis, medir interesse de compra e apoiar conversas com fornecedores, parceiros e potenciais financiadores.

O repositório público não é um convite para desenvolvimento comunitário. Materiais técnicos são disponibilizados somente para acompanhamento e avaliação, conforme `LICENSE`.

## Estado do produto

- **V0:** protótipo físico funcional, preservado como baseline.
- **V1 comercial:** revisão em planejamento técnico, definida em 2026-09-15.
- **Venda:** ainda indisponível; não há preço, reserva ou cronograma confirmado.
- **Canal público:** site, health check consolidado e GitHub Discussions.

## Promessa central

Entregar computação Linux completa em um formato portátil com tela touch, teclado físico, operação local e experiência de produto refinada.

## Comunicação pública

Publicar fatos, fotos, vídeos, metas e resultados consolidados. Não publicar credenciais, rede interna, configuração de segurança, dados pessoais, esquemas sensíveis ou alegações não validadas.

Sempre distinguir:

- **medição real:** obtida no protótipo;
- **meta de engenharia:** resultado pretendido e ainda não validado;
- **candidato técnico:** componente em avaliação;
- **comprado/instalado:** somente com confirmação física ou comprovante.
