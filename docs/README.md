# Documentação de engenharia

Use esta pasta para documentação que explica como construir, operar, integrar e entregar o SatoOne. As regras e requisitos normativos permanecem em `specifications/`.

## Rotas principais

- `product/`: posicionamento comercial e política de comunicação pública.
- `development/V1_DEVELOPMENT_PLAN.md`: plano integrado da V1.
- `development/V1_ACCEPTANCE_PLAN.md`: critérios e gates de validação.
- `electronics/V1_POWER_SYSTEM.md`: energia, proteção e telemetria.
- `cad/V1_ENCLOSURE_PLAN.md`: direção de case e cooling.

As decisões técnicas atuais da V1 foram tomadas em 2026-09-15 e consolidadas na documentação em 2026-09-16.
